🧾 Параметры, которые ОБЯЗАТЕЛЬНО нужно логировать
1️⃣ CL/OL Fueling* (status)

8 → Closed Loop
10 → Open Loop ✅
Используются только строки со значением 10

2️⃣ Mass Airflow Sensor Voltage (V)

Ось MAF таблицы

Используется для привязки лог-сэмплов к таблице

Не редактируется

3️⃣ Primary Open Loop Map Enrichment (estimated AFR)

AFR, который запрашивает ECU

Используется как AFR Target

Должен быть в тех же единицах, что wideband

4️⃣ AEM UEGO Wideband (AFR Gasoline)

Фактический AFR

Используется как AFR Measured

Должен быть откалиброван

⚠️ Необязательные (для контроля, но не участвуют в расчётах)

Engine Speed (RPM)

Mass Airflow (g/s)

Throttle Opening Angle (%)

Manifold Absolute Pressure

(логируются по желанию, утилита их игнорирует)

🚗 Как снимать логи

Передача: одна и та же (обычно 3-я)

Режим: WOT

Дроссель: 100%

Заезд: от низких оборотов до отсечки

Количество логов: минимум 2, лучше 3–5

🧮 Формула пересчёта
New MAF Flow = Old MAF Flow × (AFR_measured / AFR_target)


Богато → MAF уменьшается

Бедно → MAF увеличивается

📊 Интерпретация результата

Bins with data < MAF rows — нормально

Пустые точки:

остаются без изменений

Коррекции ±10–15% на первом проходе — нормально

Цель после 2–3 итераций: ±2–3%

❗ Важно помнить

Не сглаживает таблицу

Не интерполирует ось

Не «угадывает» значения

Делает ровно то, что видно в логах

✅ Рекомендуемый рабочий процесс

Залить текущую MAF

Снять 2–3 WOT лога

Пересчитать MAF

Залить новую MAF

Повторить при необходимости
