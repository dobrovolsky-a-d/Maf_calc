# VE-Calc

REQUIRED LOG PARAMETERS:
- Engine Speed (RPM)
- Manifold Absolute Pressure (PSI)
- Wideband AFR (Actual)
- Target AFR
- - Throttle Position (%)

RECOMMENDED:

- Injector Duty Cycle (%)
- Intake Air Temperature

NOTES:
- Log stable conditions only
- No transient throttle
- MAP must be in PSI
